# Household inventory persistence rules
This fixture represents an existing shipped SQLite database synchronized through SQLiteData/CloudKit. Shipped migrations are immutable. Add named migrations; never drop or rename shipped synced columns/tables and never add unique indexes to synced tables. New synced tables need registration in the consuming app's sync table registry. Backward-compatible defaults and mixed old/new device versions matter. Do not require destructive down migrations. No application database or CloudKit environment is supplied. Assess proposals without changing the rules.
