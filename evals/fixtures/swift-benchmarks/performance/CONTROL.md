# Performance control
Review a proposal, not a captured result: keep the same device/OS, Release build configuration, data/images, search terms and interaction script; record baseline and candidate after warmup with repeated runs and raw trace artifacts. Track median and spread of operation latency plus hitching/memory where relevant. Exclude setup and network variance from the measured interval consistently. No trace is supplied and no improvement is claimed. Decide whether this is a sensible experiment and name remaining checks. Do not invent a bottleneck or insist on Lighthouse for the native app.
