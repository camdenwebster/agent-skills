# Inventory capability extraction
The app uses SwiftUI, SQLiteData and Swift 6 strict concurrency. We want a deep InventoryQuery capability that owns filtering, sorting and read projection behavior behind a small interface. The composition root owns live database setup and dependencies. UI consumes immutable Sendable snapshots. Preserve behavior and cancellation; do not change stored schema or adopt a new framework. The proposed split instead creates ViewsPackage, ViewModelsPackage and ModelsPackage, exposing the database through a shared singleton imported by all three. Assess the proposal and recommend a focused boundary plus verification strategy. This is a design task; do not build a full package tree or rewrite the app.
